# Портал «Голоса Нижневартовска»

Цифровая карта памяти города — социально-ориентированный школьный проект, 2026/2027.

## Состав архива

```
golosa_portal/
├── index.html        — главная страница
├── about.html        — о проекте: паспорт, план-график, риски
├── history.html      — история Нижневартовска
├── map.html          — интерактивная карта памяти (6 демо-точек, фильтры)
├── archive.html      — архив интервью, фото и документов (демо)
├── team.html         — команда проекта
├── contacts.html     — контакты и форма обратной связи
├── css/style.css     — общие стили
├── js/main.js        — вся логика (счётчики, карта, фильтры, форма)
├── data/points.js    — точки карты памяти (легко редактировать!)
└── assets/hero.jpg   — фоновое изображение шапки
```

## Как запустить на MacBook

### Способ 1 — просто открыть (самый быстрый)
1. Распакуйте архив (двойной клик по `.zip`).
2. Откройте папку `golosa_portal` и дважды кликните по файлу `index.html`.
   Сайт откроется в браузере (Safari, Chrome — любой).

### Способ 2 — локальный сервер (рекомендуется)
Чтобы карта Яндекса и все функции работали корректно, запустите локальный сервер:

1. Откройте **Терминал** (Launchpad → Другие → Терминал, или Spotlight: Cmd+Пробел → наберите «Terminal»).
2. Перейдите в папку проекта (перетащите папку в окно Терминала после команды `cd `):
   ```bash
   cd /путь/до/golosa_portal
   ```
3. Выполните:
   ```bash
   python3 -m http.server 8080
   ```
4. Откройте в браузере: **http://localhost:8080**

Остановить сервер: вернитесь в Терминал и нажмите `Ctrl + C`.

> macOS уже имеет Python 3, ничего устанавливать не нужно.

## Node.js-режим (рекомендуется для админки и формы)

В архиве есть `server.js` — бэкенд на чистом Node.js **без установки пакетов**:

```bash
node server.js        # или: npm start
```

Откроется `http://localhost:3000`. В этом режиме:
- форма «Контакты» отправляет заявки в **общую базу** (`data/store.json`), их видит вся команда в админке;
- точки карты и архив из админки сохраняются на сервере, а не в одном браузере;
- появляется API: `/api/health`, `/api/messages`, `/api/data`.

Если сервер не запущен, портал автоматически переключается на локальное хранилище браузера (localStorage) — на статическом хостинге всё тоже работает. Режим отображается в админке.

## Как редактировать

- **Точки карты** — файл `data/points.js`. Добавьте объект в массив `POINTS`:
  ```js
  {id:7, title:"Новое место", year:"1980", coords:[60.94,76.57],
   category:"culture", text:"Описание..."}
  ```
  Координаты берите из Яндекс.Карт (ПКМ по точке → «Что здесь?»).
- **Записи архива** — массив `ITEMS` в `js/main.js` (раздел «Архив»).
- **Контакты** — текст в `contacts.html` (замените email и школьный номер).

## Технологии

Чистые HTML + CSS + JavaScript. Без сборки, зависимостей и интернет-пакетов (кроме встроенной Яндекс.Карты).


## Установка как приложение (PWA)

Портал теперь является прогрессивным веб-приложением (PWA):
- работает **офлайн** (все страницы кэшируются Service Worker'ом);
- устанавливается на **iPhone и Android** как обычное приложение;
- страница-инструкция: `install.html`.

**iPhone (Safari):** открыть сайт → «Поделиться» → «На экран “Домой”».
**Android (Chrome):** открыть сайт → меню (три точки) → «Установить приложение».

> Service Worker работает только по http(s):// или localhost — просто двойной клик по файлу офлайн не включит. Для офлайна используйте `python3 -m http.server` (см. выше) или разместите портал на любом хостинге.

## Как выложить в интернет (для приложения нужен https)

Варианты с бесплатным HTTPS:
1. **GitHub Pages** — репозиторий → Settings → Pages. HTTPS включён автоматически.
2. **Netlify** — перетащите папку на app.netlify.com — через минуту сайт с HTTPS.
3. **Vercel** — аналогично, `vercel deploy` или перетаскивание папки.

После публикации откройте полученный https-адрес на телефоне и установите приложение по инструкции выше.


## Если что-то не работает

**Карта не показывает точки или пустой список:**
- откройте `map.html` через локальный сервер (`python3 -m http.server 8080`), а не двойным кликом — браузеры блокируют загрузку файлов с диска (file://);
- проверьте, что файл `data/points.js` лежит рядом с остальными и в `map.html` есть строка `<script src="data/points.js"></script>` перед `main.js`.

**Сама Яндекс.Карта (справа) серый квадрат:**
- нужен интернет — карта подгружается онлайн. Без сети работают все тексты, список точек и остальные страницы.

**Страницы открылись без стилей:**
- не переименовывайте и не перемещайте папки `css/`, `js/`, `assets/` — пути в HTML относительные.

**Проверка за минуту:** откройте в браузере `http://localhost:8080/map.html` — слева должен быть список из 6 точек, справа — карта Нижневартовска.
